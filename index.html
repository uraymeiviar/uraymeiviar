Early Explorations & Undocumented Archives

DOS · Windows 3.1 · OS/2 Warp · Windows 95 · Early Explorations
Pre-2008

A significant portion of my early engineering journey remains undocumented or lost to time. Starting from the MS-DOS era, Windows 3.1, OS/2, and Windows 95, I built countless utilities, simple games, and creative weekend experiments that have since vanished with legacy magnetic media and aging hard drives. While the vast majority of these programs were authored in C and C++, I also programmed extensively in Pascal, developed commercial business software using Borland Delphi and C++Builder, crafted Java applications for university demonstrations, built numerous web projects in JavaScript, and tinkered with hardware interfaces and x86/x64 assembly. Alongside these were several custom 3D game engines that were never finished—each serving as an invaluable sandbox where I honed my understanding of low-level systems, mathematical modeling, and deterministic real-time execution from first principles.
