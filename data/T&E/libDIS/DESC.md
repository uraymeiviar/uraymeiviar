# libDIS - IEEE 1278 Protocol Engine

**Role:** Protocol Architect & Author  
**Domain / Tags:** C++, DIS/HLA, Networking, Protocols, Real-Time

## Executive Summary
In-house C++ library implementing the IEEE 1278 Distributed Interactive Simulation (DIS) protocol for low-latency networked simulation.

## Key Technical Highlights
- Full PDU serialization/deserialization (Entity State, Fire, Detonation, Collision, Radio Communications).
- Dead reckoning algorithms (position, velocity, dead-reckoning extrapolation) for smooth cross-network entity movement.
- Serves as the mission-critical networking backbone connecting aircraft, tank, and joint command simulators.
