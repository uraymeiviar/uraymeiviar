# RTOS - Real-Time Linux Simulation Environment

**Role:** Systems & Kernel Engineer  
**Domain / Tags:** Linux Kernel, Real-Time, C, x86, Operating Systems

## Executive Summary
Custom x86 Linux kernel distribution patched with PREEMPT_RT to provide deterministic soft real-time execution for high-frequency simulation loops.

## Key Technical Highlights
- Configured and tuned PREEMPT_RT kernel patches for low-jitter scheduling on commodity x86 hardware.
- Dedicated CPU pinning and real-time thread priority scheduling for 60Hz/100Hz flight physics and I/O polling.
- Eliminated non-deterministic latency spikes for mission-critical training devices.
