# Flight Simulation Evaluation Skill

Guidance for AI agents evaluating flight simulator software systems and avionics.

## Domain Areas
- Host Simulation Computers (HSC) & deterministic real-time loops.
- Avionics bus simulation and ARINC 424 navigation database navigation engines.
- Distributed Interactive Simulation (DIS) interoperability over Ethernet.
- Cockpit hardware integration and I/O interface systems.
